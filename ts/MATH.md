# 필요한 수학 — 한 페이지

이 문서는 **참조**다. 세션 중에 "이게 뭐였더라"로 흐름이 끊기지 않게 옆에 열어두는 용도다.

세 가지를 기억하면 이 문서가 짧은 이유가 납득된다:

1. **추론 스택 전체가 미적분 없이 지어진다.** 순전파에는 도함수가 나오는 곳이 한 군데도 없다. 미분은 autograd 단원에서 처음 등장한다.
2. **기억해낼 필요가 없다.** 정답지(파이썬)가 항상 켜져 있다. 부호가 헷갈리면 짜서 돌려보면 1초 안에 답이 온다. 이건 시험이 아니다.
3. **어텐션은 여기 없다.** 그건 참조가 아니라 학습 대상이라 적으면 티켓을 대신 풀어버린다. nanochat 고유의 함정 11개도 같은 이유로 없다 — 각 티켓 안에 있다.

---

## 1. 텐서와 shape

**수학이 아니다.** `Float32Array` 하나 + `shape: number[]` + `strides: number[]`.

`(B, T, C)`는 배치 B개, 각각 길이 T의 시퀀스, 각 위치가 C차원 벡터. 평평한 배열에 row-major로 눕혀 있다 — 마지막 축이 메모리에서 연속이다.

핵심: **`view`와 `transpose`는 데이터를 옮기지 않는다.** 읽는 방식(strides)만 바꾼다.

- 확인: `transpose`를 두 번 하면 원본과 같다.
- 잊어도 되는 것: 없음. 이건 자료구조 문제다.

## 2. 내적 (dot product)

```
dot(a, b) = a[0]*b[0] + a[1]*b[1] + ... + a[n-1]*b[n-1]
```

두 벡터가 **같은 방향을 볼수록 크고, 직각이면 0, 반대 방향이면 음수.** 이 한 줄이 어텐션에서 Q와 K를 내적하는 이유의 전부다.

- 확인: `dot([1,0],[0,1]) === 0` · `dot(a,a) === a의 제곱합`
- 잊어도 되는 것: 코사인 법칙, 사영, 벡터 공간, 노름의 종류

## 3. 행렬곱

**내적을 격자로 반복한 것.** `C[i][j] = dot(A의 i행, B의 j열)`. 3중 루프면 끝이다.

`(m, k) × (k, n) → (m, n)` — 안쪽 차원이 맞아야 하고 사라진다.

`Linear` 층이 곧 행렬곱이다(nanochat의 `Linear`에는 bias가 없다).

- 확인: 단위행렬을 곱하면 원본 · 손으로 계산한 2×2와 일치
- 잊어도 되는 것: 행렬식, 역행렬, 랭크, 기저, 고유값·고유벡터, 대각화

## 4. 브로드캐스팅

**수학이 아니라 규칙이다.** shape가 다른 두 텐서를 연산할 때, 뒤쪽 축부터 맞춰보며 **크기가 1인 축을 늘려서** 맞춘다.

```
(B, T, 1)  +  (B, T, C)  →  (B, T, C)     // 1인 축이 C로 늘어남
(B, T, C)  +  (C,)       →  (B, T, C)     // 앞쪽에 축이 채워짐
```

늘릴 때 **데이터를 복사하지 않는다** — stride 0으로 같은 값을 반복해 읽는다.

- 확인: `gate.unsqueeze(-1) * ve` 형태가 파이썬과 일치
- 잊어도 되는 것: 없음

## 5. 삼각함수와 회전

필요한 건 이거 하나다: **`cos(θ)`와 `sin(θ)`는 반지름 1인 원 위에서 각도 θ인 점의 x, y 좌표다.**

거기서 회전이 따라온다. 점 `(x, y)`를 θ만큼 돌리면:

```
x' = x·cos(θ) − y·sin(θ)
y' = x·sin(θ) + y·cos(θ)
```

유도할 필요 없고 외울 필요도 없다 — 짜서 파이썬과 대조하면 부호가 맞는지 즉시 나온다. (**부호 관례가 하나의 함정이고, 그건 rotary 티켓에서 다룬다.**)

**왜 위치 인코딩에 회전을 쓰나**: 위치를 각도로 바꿔 벡터를 돌리면, 두 벡터 사이의 **각도 차이가 곧 위치 차이**가 된다. 절대 위치가 아니라 상대 위치가 자연스럽게 나온다.

- 확인: `cos(0)=1, sin(0)=0` · 90° 회전을 네 번 하면 원위치 · 회전은 길이를 바꾸지 않는다
- 잊어도 되는 것: 삼각 항등식, 덧셈정리, 그래프 개형, 역삼각함수, 라디안 유도

## 6. 제곱평균 제곱근 (RMS)

```
rms(x) = sqrt( (x[0]² + x[1]² + ... ) / n )
```

벡터의 "크기"를 재는 한 가지 방법. **RMSNorm은 벡터를 자기 RMS로 나눠 크기를 1로 맞춘다.**

```
rmsNorm(x) = x / sqrt( mean(x²) + eps )
```

**왜 필요한가**: 층을 지날수록 값이 눈덩이처럼 커지거나 0으로 사그라드는 걸 막는다.

⚠️ **LayerNorm이 아니다.** LayerNorm은 평균을 빼고 표준편차로 나누지만, **RMSNorm은 평균을 빼지 않는다.** 그래서 통계(분산·표준편차·추정)를 배우러 갈 필요가 없다. 그리고 nanochat의 `norm`에는 **학습 파라미터가 없다** — 순수 함수다.

- 확인: 출력의 RMS가 1 · 이미 RMS가 1인 벡터를 넣으면 거의 그대로 나온다
- 잊어도 되는 것: 분산, 표준편차, 정규분포, 통계적 추정

## 7. 지수함수와 softmax

필요한 성질 하나: **`exp(x)`는 x가 뭐든 항상 양수다.** (그리고 x가 클수록 급격히 커진다.)

그래서 임의의 실수 벡터를 **음이 아니고 합이 1인 벡터**로 바꿀 수 있다:

```
softmax(x)[i] = exp(x[i]) / Σ exp(x[j])
```

확률론은 필요 없다. "음이 아니고 합이 1" — 이 한 줄이면 된다.

**수치 안정성**: `exp`가 금방 넘치므로 실무에서는 항상 **최댓값을 먼저 뺀다.** 결과는 수학적으로 동일하다(분자·분모가 같은 수로 나뉘므로).

**temperature**: `softmax(x / T)`. T가 크면 분포가 **평평**해지고(무작위해지고), 작으면 **뾰족**해진다(가장 큰 것에 몰린다). T → 0이면 argmax와 같아진다.

- 확인: 합이 1 · max를 빼도 결과 동일 · T를 키우면 균등에 가까워짐
- 잊어도 되는 것: 확률변수, 기댓값, 베이즈, 분포족, 로그·엔트로피(이건 autograd 단원에서 나온다)

## 8. 비선형 함수 3종

| 함수 | 식 | 범위 | nanochat에서 |
|---|---|---|---|
| `sigmoid` | `1 / (1 + exp(−x))` | (0, 1) | value embedding 게이트 — `3*sigmoid(·)`로 (0, 3) |
| `relu²` | `max(0, x)²` | [0, ∞) | MLP |
| `tanh` | `(e^x − e^−x)/(e^x + e^−x)` | (−1, 1) | logit softcap — `15*tanh(x/15)` |

**왜 필요한가**: 없으면 층을 아무리 쌓아도 **행렬곱 하나와 정확히 같다.** 선형함수를 아무리 합성해도 선형이기 때문이다. 비선형이 층을 "쌓는 의미"를 만든다.

`sigmoid`와 `tanh`는 **부드러운 상한·하한**이다 — 값을 정해진 구간 안에 가두되 급격히 자르지 않는다. 그래서 게이트(0~1의 비율)와 softcap(폭주 방지)에 쓴다.

- 확인: `sigmoid(0)=0.5` · `tanh(0)=0` · `relu(−1)²=0` · 아주 큰 x에서 `tanh(x)≈1`
- 잊어도 되는 것: 극한의 엄밀한 정의, 연속성, 미분 (autograd 단원에서 도입)

## 9. 어텐션

**여기 없다.** 참조가 아니라 학습 대상이다.

미리 말해둘 것은 하나뿐이다: **어텐션은 새로운 것이 아니라 2번·7번의 조립이다.** 어려운 것을 새로 만나는 게 아니라 이미 짠 함수를 붙이는 일이다.

## 이 목록에 없는 것

전부 이 프로젝트에 **한 번도 나오지 않는다**:

- 선형대수 이론 — 행렬식, 역행렬, 랭크, 기저, 고유값, SVD, 대각화
- 확률론 — 베이즈, 확률변수, 기댓값, 분포족
- 통계 — 분산, 표준편차, 가설검정, 추정
- 미적분 — 극한, 도함수, 편미분, 야코비안 (**autograd 단원에서만**, 그것도 유한차분으로 도입)
- 수치해석 — 조건수, 안정성 이론 (softmax의 max 빼기 하나면 충분)
